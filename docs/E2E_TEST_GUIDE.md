# E2Eテストガイド

このドキュメントは、Logseqプラグイン「Show weekday and week-number」のE2E（エンドツーエンド）テスト手順を説明します。

## 前提条件

- Logseqがインストールされていること
  - **ファイルグラフ用**: Logseq 0.10.x (例: 0.10.15)
  - **DBグラフ用**: Logseq 2.x (例: 2.0.1)
- プラグインがビルドされていること (`pnpm build` を実行)

## テスト環境の準備

### 1. テストグラフの作成

ファイルグラフの場合:

1. 新しいフォルダを作成（例: `C:\temp\logseq-test-graph`）
2. その中に `logseq` フォルダを作成
3. `logseq\config.edn` を作成（空ファイルで可）
4. `journals` フォルダを作成
5. サンプルのジャーナルファイルを作成:
   ```
   journals\2024_01_01.md
   journals\2024_01_02.md
   journals\2024_01_03.md
   ```

### 2. Logseqの起動

1. Logseqを起動
2. グラフ選択画面でテストグラフのフォルダを選択
   - ファイルグラフ: 作成したフォルダを指定
   - DBグラフ: 「Create db graph」を選択

### 3. 開発者モードの有効化

1. `...` メニュー → Settings → Advanced
2. **Developer mode** を有効化

### 4. プラグインのロード

1. `...` メニュー → Plugins
2. **Load unpacked plugin** をクリック
3. プラグインのルートディレクトリを選択
   ```
   D:\Resource\GitHub\logseq-plugin-show-weekday-and-week-number
   ```
4. プラグインがリストに表示されることを確認
5. プラグインを有効化

## 動作確認チェックリスト

### A. 基本機能

- [ ] **曜日表示**: 日次ジャーナルタイトルの横に曜日が表示される
- [ ] **週番号表示**: 設定に応じて週番号が表示される
- [ ] **相対時間表示**: 「昨日」「今日」「明日」などの相対表示が正しく動作

### B. カレンダー機能

- [ ] **2行カレンダー**: 左サイドバーに2行カレンダーが表示される
- [ ] **今日の日付**: 今日の日付がハイライト表示されている
- [ ] **ホリデー表示**: 祝日が正しく表示される（設定に応じて）
- [ ] **ICSイベント**: ICSカレンダー連携が動作する（設定に応じて）
- [ ] **ページ存在確認**: 既存のページには下線が表示される

### C. ナビゲーション機能

- [ ] **週次ジャーナル**: 週次ジャーナルへのナビゲーションが動作
- [ ] **月次ジャーナル**: 月次ジャーナルへのナビゲーションが動作
- [ ] **四半期ジャーナル**: 四半期ジャーナルへのナビゲーションが動作
- [ ] **年次ジャーナル**: 年次ジャーナルへのナビゲーションが動作

### D. 設定項目

- [ ] **週番号フォーマット**: ISO/US フォーマット切り替えが動作
- [ ] **カラー設定**: 週末カラー、祝日カラーが適用される
- [ ] **言語設定**: 翻訳が正しく適用される

## コンソールエラーの確認

1. Logseqウィンドウ内で `Ctrl+Shift+I` を押してDevToolsを開く
2. Consoleタブを選択
3. 「Errors only」にフィルタを適用
4. プラグイン関連のエラーがないか確認

## DBグラフでのテスト

DBグラフ（Logseq 2.x）でのテストは、ファイルグラフと同様の手順で実施しますが、以下の点に注意:

- DBグラフではスラッシュを含むページ名（例: `2024/01/01`）が作成できない
- 週次ジャーナルのフォーマット設定をスラッシュなしにすること
- GPUレンダリングの問題がある場合は、`--disable-gpu` フラグで起動

## 既知の問題

- Jestでのユニットテストは`@logseq/libs`がブラウザ環境を必要とするため実行不可
- 本格的な自動化テストにはPlaywrightやCypressなどのE2Eフレームワークが推奨される
